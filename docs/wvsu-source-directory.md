# WVSU Official Source Directory

This directory organizes the official WVSU pages provided for expanding StringerAI's coverage. Tracking query parameters have been removed from the links. A page listed here is a research/source reference; it is not automatically crawled or added to the runtime knowledge base. Only facts represented in `stringerai/data/wvsu_knowledge_base.json` are currently searchable by the chatbot.
